# A 股早盘 Telegram 量价观察

## 行为与范围

新增独立工作流 `.github/workflows/ashare.yml`，北京时间工作日 10:00 触发（UTC 02:00），并用沪深交易所2026年度官方休市公告跳过休市日。调休周末仍休市。未核验的2027年及以后会停止，不会假设所有工作日开市；年底前应更新日历。

GitHub Actions 可能延迟或漏触发。只有北京时间10:00–10:20允许构建和发送；超过窗口直接跳过，不在几小时后补发“早盘”结论。因此该免费调度方式不能保证准点或每天一定送达。年度日历不能预知临时休市；可暂停工作流，或把仓库变量 `ASHARE_DISABLED` 设为 `true` 紧急停发。恢复时删除该变量或设为 `false`。

只读取现有 `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID` secrets，沿用已核对的私人聊天，不更改凭证、权限、晚间GitHub日报和独立邮件任务。不调用付费AI，不交易。发布本工作流到默认分支即配置定时发送；手动 `Run workflow` 永远只预览，不发送。

## 行情与规则

腾讯财经免费公开接口 `https://qt.gtimg.cn/q=`；非交易所直连，也没有稳定API契约保证。全流程不缓存旧行情作为当前行情，不下载新闻或引入额外模型。

- 指数：上证指数、深证成指、创业板指。逐一展示成交额，不把重叠口径相加成两市成交额。
- 固定20只观察池在 `ashare.py` 的 `WATCHLIST` 列出，跨多个行业但不是全市场、指数成分完整样本或个性化投资组合。选择是工程默认样本，不代表投资优先级。
- 校验证券代码、有限数值、价格/涨跌幅/涨跌额一致性、当前日期、行情年龄最多180秒；指数缺一即停止。个股无效则剔除，有效覆盖不足80%停止。
- 腾讯字段以0起下标计算：现价3、昨收4、今开5、时间30、涨跌额31、涨跌幅32、高低33/34、原始成交量36、成交额57（万元，缺失时37取整万元）、量比49。成交量单位随证券类型不同，不归一、不参与排名，仅验证为正；0量比按不可用处理。
- 候选规则：涨幅0.5%–5%，现价不低于今开，成交额至少1亿元，腾讯量比至少1.2，剔除ST/退市等特殊名称。
- 排序：相对上证的涨幅百分点 + min(腾讯量比, 3)，并以代码固定破同分。最多5只；不足3只如实少列，无信号保持空名单。
- 指数情景仅说明同步走强、同步偏弱或分化时的观察条件，不是可靠预测。候选给出今开参考与回落风险，没有目标价或收益承诺。
- 发送前重新检查工作日、时间窗口、payload年龄≤120秒和行情≤180秒。失败时Actions报错或跳过；不会为了发送而造数据。没有单独故障TG通知。
